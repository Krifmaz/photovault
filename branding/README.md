# Photovault branding

Single source for the Encore look used by the app forks (`mobile/`, `web/`, `desktop/`).

- `encore-tokens.json`: colour, radius and font tokens, copied from
  [Krifmaz/Encore](https://github.com/Krifmaz/Encore) `web-rs/static/css/app.css`
  (`data-theme="encore"` with the "logo" accent for dark; `data-theme="light"` with the
  charcoal accent from `clients/android/.../Theme.kt` for light). Each app mirrors these
  values in exactly one theme file; see that app's `PHOTOVAULT.md`.
- `icon.svg`: app icon (charcoal tile, cream-to-gold vault ring and aperture).
- `glyph.svg`: the same mark on a transparent background, for in-app logos and
  adaptive-icon foregrounds.
- `icon-1024.png`: `icon.svg` rendered at 1024 px.

Photovault is based on Ente (ente.com). Ente's name and logo are not used.
